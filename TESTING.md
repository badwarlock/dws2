# Тестирование компонента

## 🎯 Быстрая проверка без установки

Если вы хотите сразу увидеть как работает компонент **без установки зависимостей и запуска npm**, просто откройте файл в браузере:

```bash
# Откройте файл demo.html в любом браузере
open demo.html  # macOS
xdg-open demo.html  # Linux
start demo.html  # Windows
```

Или просто перетащите файл `demo.html` в окно браузера.

### Что вы увидите

- ✅ Работающее дерево с реальными данными
- ✅ Интерактивное раскрытие/закрытие узлов
- ✅ Prefetching при наведении курсора
- ✅ Цветовая кодировка типов узлов
- ✅ Логи в консоли браузера

### Панель управления

В demo.html есть кнопки:
- **Свернуть все** - закрывает все узлы
- **Развернуть все** - раскрывает первый уровень
- **Перезагрузить** - сбрасывает состояние

## 📊 Что тестировать

### Базовая функциональность

1. **Загрузка корневого уровня**
   - При открытии страницы должны загрузиться 3 узла (id: 1, 2, 3)
   - Проверьте в консоли: `[Mock Data] Request: { depth: 1 }`

2. **Prefetching при ховере**
   - Наведите курсор на узел типа `node` или `leaf`
   - Проверьте в консоли: `[Prefetch] Loading children for: ...`
   - Данные должны загрузиться в фоне

3. **Раскрытие узлов**
   - Кликните на узел `1` (type: node)
   - Узел должен раскрыться и показать дочерние элементы
   - Иконка должна измениться с ▶ на ▼

4. **Закрытие узлов**
   - Повторный клик на тот же узел
   - Дочерние элементы должны скрыться
   - Иконка должна вернуться к ▶

5. **Конечные элементы**
   - Элементы типа `account` не должны раскрываться
   - У них нет иконки раскрытия
   - Курсор остается обычным (не pointer)

### Иерархия данных

Проверьте структуру дерева:

```
Корень (depth: 1):
├── 1 (node)
│   ├── 11 (node) [depth: 2]
│   │   ├── 111 (leaf) [depth: 3]
│   │   │   ├── 1111 (account) [depth: 4]
│   │   │   └── 1112 (account) [depth: 4]
│   │   └── 112 (leaf) [depth: 3]
│   │       └── 1121 (account) [depth: 4]
│   └── 12 (leaf) [depth: 2]
│       ├── 121 (account) [depth: 3]
│       └── 122 (account) [depth: 3]
├── 2 (node)
│   ├── 21 (leaf) [depth: 2]
│   └── 22 (node) [depth: 2]
│       └── 221 (leaf) [depth: 3]
│           ├── 2211 (account) [depth: 4]
│           ├── 2212 (account) [depth: 4]
│           └── 2213 (account) [depth: 4]
└── 3 (leaf)
    ├── 31 (account) [depth: 2]
    ├── 32 (account) [depth: 2]
    └── 33 (account) [depth: 2]
```

### Визуальные элементы

1. **Отступы (indentation)**
   - Каждый уровень имеет отступ 20px
   - depth: 1 → 0px
   - depth: 2 → 20px
   - depth: 3 → 40px
   - depth: 4 → 60px

2. **Цветовая кодировка типов**
   - 🔵 `node` - голубой badge
   - 🟢 `leaf` - зеленый badge
   - 🟠 `account` - оранжевый badge

3. **Hover эффекты**
   - При наведении строка меняет фон на светло-серый
   - Курсор меняется на pointer для раскрываемых узлов

### Производительность

1. **React Query кэширование**
   - Откройте React DevTools
   - Раскройте узел, затем закройте
   - Раскройте снова - данные должны загрузиться мгновенно (из кэша)

2. **Prefetching**
   - Наведите курсор на несколько узлов
   - Не кликайте, просто наводите
   - При клике данные должны загрузиться мгновенно

3. **Мемоизация**
   - Раскройте несколько узлов
   - Раскройте еще один узел
   - Предыдущие узлы не должны ре-рендериться

## 🐛 Отладка

### Включите подробные логи

Откройте консоль браузера (F12) и вы увидите:

```javascript
[App] Environment variables: { ... }
[MOCK MODE] Fetching data for: { depth: 1 }
[Mock Data] Request: { depth: 1 }
[Mock Data] Response: { count: 3, data: [...] }
```

### Проверка состояния React Query

Добавьте React Query DevTools (опционально):

```bash
npm install @tanstack/react-query-devtools
```

В `src/App.tsx`:

```typescript
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';

// Добавьте в JSX:
<ReactQueryDevtools initialIsOpen={false} />
```

### Типичные проблемы

**Проблема:** Ошибка при загрузке данных

**Решение:**
1. Проверьте консоль на наличие ошибок
2. Убедитесь, что `VITE_USE_MOCK_DATA=true` в `.env`
3. Перезапустите dev сервер

**Проблема:** Узлы не раскрываются

**Решение:**
1. Проверьте, что кликаете на узел типа `node` или `leaf`
2. Элементы `account` не раскрываются по дизайну
3. Проверьте логи в консоли

**Проблема:** Префетчинг не работает

**Решение:**
1. Откройте консоль и проверьте логи prefetch
2. Убедитесь, что наводите на узел, а не на `account`
3. Данные могут быть уже в кэше
