# 🚀 Быстрый старт (Quick Start)

## ⚡ Самый быстрый способ (без установки)

Просто откройте файл **demo.html** в браузере!

```bash
# Откройте файл в браузере
open demo.html        # macOS
xdg-open demo.html    # Linux
start demo.html       # Windows

# Или перетащите demo.html в окно браузера
```

**Готово!** 🎉 Компонент сразу работает с демо-данными.

---

## 📦 Запуск проекта за 3 шага (с npm)

### 1. Установите зависимости
```bash
npm install
```

### 2. Запустите dev-сервер
```bash
npm run dev
```

### 3. Откройте браузер
```
http://localhost:5173
```

**Готово!** 🎉 Компонент работает с тестовыми данными.

---

## Что дальше?

### Тестирование функционала

1. **Наведите курсор** на узел → произойдет prefetch данных
2. **Кликните на узел** → дерево раскроется
3. **Повторный клик** → узел закроется

### Типы элементов

- 🔵 **node** - может содержать другие узлы
- 🟢 **leaf** - содержит только accounts
- 🟠 **account** - конечный элемент, не раскрывается

---

## Подключение вашего API

Создайте файл `.env`:

```env
VITE_API_BASE_URL=https://your-api-url.com
VITE_USE_MOCK_DATA=false
```

Или скопируйте:
```bash
cp .env.example .env
# Отредактируйте .env в вашем редакторе
```
